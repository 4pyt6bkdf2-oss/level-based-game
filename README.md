# 回声快递 · Echo Courier

一个 2D 横向卷轴闯关小游戏。记录自己的行动，让“回声”重走路线并停在终点，帮你踩住机关、维持光桥。三关包含二段跳、能量收集、双机关配合和无限重试。

## 开始游戏

下载仓库后，用现代浏览器打开根目录的 **`index.html`** 即可。无需安装依赖，也不需要后端服务。

也可以在仓库目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或 ← / → | 左右移动 |
| 空格 / W / ↑ | 跳跃；空中再按一次可二段跳 |
| E | 开始记录；再次按下生成回声 |
| Q | 取消当前记录，或撤销最新回声 |
| R | 重试本关 |
| P / Esc | 暂停 / 继续 |

触屏可使用画面下方的按钮。音效默认关闭，可自行开启。记录最多 6 秒，同时最多保留 2 个回声。集齐本关全部能量后，进入最右侧的信标过关。

## 修改源码

- `src/echo-courier.html`：游戏界面、样式、关卡和逻辑的可编辑源码。
- `scripts/standalone-template.html`：独立运行所需的页面容器、样式和状态存储适配。
- `scripts/build.py`：把源码嵌入容器，生成可分发的单文件网页。
- `tests/game.cjs`：使用实际游戏逻辑检查三关通关路线、回声、重试和掉落复活。
- `index.html`：已构建的可玩版本。

修改源码后，使用 Python 3 重新构建：

```sh
python scripts/build.py
```

安装 Node.js 后可以运行无第三方依赖的逻辑检查：

```sh
node tests/game.cjs
```

页面适配桌面和窄屏，支持系统明暗主题。关卡进度会尝试保存在浏览器本地；隐私模式或禁用存储时，游戏仍可运行，但进度可能不会保留。

## 静态托管

可将 `index.html` 上传到任意静态网站服务。若使用 GitHub Pages，在仓库设置中选择从 `main` 分支的根目录发布即可。
